# MonsterRoutePreview · 怪物路线显示 1.0.3

与旧版 BepInEx 的 MonsterRoute 逻辑和 AstralParty.Runtime 的实际代码逐项比对后：

- 第一只怪物的骰子动画进行中也允许显示步数，不再以 `showDicePoint.playing` 隐藏提示。
- 直接继承原版 `txt_DicePoint` 的字体、字号、颜色、描边和阴影参数，避免自动清除描边。
- 第一次地图资源尚未完成时依次加载道路，至少一条道路完成后再加载落点特效。
- 怪物的步数归零但尚在同一个行动回合时，保留已经请求的道路，避免首次异步加载被提前清除。
- 首次资源加载长期无响应时最多重试六次；回合变化、战斗弹窗、场景卸载时进行清理。

这是基于源码的调整，需在真实首怪物、加速回合、战斗开始/退出的场景中核验显示效果。
